# chain-reader-cli

This repo is chain-reader-cli: A Go command-line tool that reads the latest block and account balances from an Ethereum RPC endpoint using go-ethereum

Language: go

## How to work with me

- I'm learning, so explain each change and the reasoning behind it.
- Always run the tests after changing code, and show me the output:

```bash
go run .
go test ./...
go vet ./...
gofmt -l .
```

### Learning Go
- I know Python and Solidity well, and I'm new to Go. Explain Go ideas by comparing them to those two.
- When you introduce a Go feature for the first time, explain it in one or two sentences.
- When I ask for a hint, give one hint only. Don't write the solution.
- When I review code, ask me what I expect it to do before you tell me.
